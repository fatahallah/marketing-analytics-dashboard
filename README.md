## 💡 Core Features & Business Value

- **Dynamic Data Filtering:** Real-time metrics breakdown across 6 core product categories (Wines, Meat, Gold, Fish, Fruits, Sweets).
- **Interactive KPI Cards:** Instantly recalculates Total Spend ($1.4M+), Conversions, Average Income, and Order Volumes.
- **Campaign Response Heatmap:** Acceptance matrix grid evaluating customer response rates across Marketing Campaigns 1 to 5.
- **Client-Side CSV Export:** One-click custom analytics reporting exported directly from active filtered state.
- **Responsive Dark Theme:** Tailwind CSS glassmorphic UI designed for executive reporting and desktop/mobile usability.
